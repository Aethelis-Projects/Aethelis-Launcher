# ADR-0015: Сохранение организации и репозитория Aethelis-Launcher для непрерывности дистрибуции

- **Статус**: Принято
- **Дата**: 2026-09-12
- **Контекст**:
  Проект Nord Launcher является архитектурным и идеологическим greenfield-преемником проекта Aethel (согласно ADR-0008: Clean Slate). Исходная организация на GitHub — `Aethelis-Projects`, а открытый репозиторий для публикации был предоставлен владельцем по адресу:
  `https://github.com/Aethelis-Projects/Aethelis-Launcher`

  Возникает вопрос согласованности брендинга: следует ли форсированно требовать создание новой организации `Nord-Launcher` до первого релиза, либо сохранить текущий репозиторий с чётким разграничением имени продукта.

- **Решение**:
  1. **Имя продукта**: Внутри кодовой базы, в бинарных сборках (`NordLauncher.exe`), в заголовке окна Wails, в инсталляторе NSIS (`NordLauncher-Setup.exe`), в манифестах авто-обновлений и во всех документах проект именуется исключительно **Nord Launcher**.
  2. **Репозиторий дистрибуции**: Исходный код публикуется в репозитории `github.com/Aethelis-Projects/Aethelis-Launcher` для сохранения существующей аудитории, прав доступа и подписок организации.
  3. **План плавного ребрендинга (Alias/Redirect)**: Владелец репозитория может в любой момент переименовать репозиторий в `Nord-Launcher` через настройки GitHub (`Settings -> Repository Name -> Rename`). GitHub автоматически создаёт неразрывный HTTP-редирект со старого URL `Aethelis-Projects/Aethelis-Launcher` на новый `Aethelis-Projects/Nord-Launcher` без поломки существующих `git clone` и ссылок.

- **Последствия**:
  - Исключена путаница в исходном коде: весь исполняемый код и UI брендированы как Nord Launcher.
  - Сохранена полная преемственность GitHub Stars, Issues и прав доступа организации.
