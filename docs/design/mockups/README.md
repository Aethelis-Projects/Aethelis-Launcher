# Reference Mockups & Visual Study

Directory for reference screenshots and mockups of inspiration sources (Modrinth App, Prism Launcher, Linear, Steam, Raycast).

## How to use:
1. Place reference screenshots (`.png`, `.jpg`) into this directory.
2. Run `hallmark study <path_to_image>` or invoke analysis to extract visual DNA (macrostructures, color tokens, typographic hierarchy).
3. The extracted tokens are merged into `docs/design/design.md`.
4. Pixel copying is prohibited; only structural rhythm and ergonomic layout principles are adopted.
