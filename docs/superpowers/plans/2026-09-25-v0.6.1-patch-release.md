## 1. Overview & Root Cause Analysis

### H1 & H2: Mod Update Duplication & Phantom Updates
- **Problem:** Updating a mod via `InstalledModsManager` called `InstallMod`, which downloaded the new file without removing the old `.jar` file and without reconciling duplicate entries. As a result, both files remained active on disk and in `nord-installs.json`. The update checker continued to see the old version as installed and offered an update again.
- **Solution (F1):** Introduce a dedicated `UpdateMod` atomic replacement pipeline: download candidate to temporary file, verify checksum, write target `.jar`, delete the old `.jar`, and update the manifest record in place (`Replace`). Implement automatic self-heal during reconcile so that any existing duplicate active jars for the same mod have the older/extra file renamed to `.jar.disabled` with a UI toast offering undo.

### H3: Java Version Recommendations & Matrix Defect
- **Problem:** `java_matrix.json` lacked an upper bound on Minecraft 1.20.5+ and had no entry for 26.1+ (Mojang's new annual versioning scheme where 26.1..26.3 requires Java 25). `DownloadRuntime(major <= 0)` resolved to Java 21 regardless of whether the instance required Java 25 or Java 8/17.
- **Solution (F2):** Update `java_matrix.json` and `ResolveJavaMajor` with accurate boundaries:
  - `<= 1.16.5`: Java 8 (legacy)
  - `1.17` - `1.20.4`: Java 17
  - `1.20.5` - `26.0`: Java 21
  - `26.1+`: Java 25
  In `JavaManager.tsx`, expand the offer list to all LTS majors `{8, 11, 17, 21, 25}`. In `InstanceSettingsModal.tsx`, show an informative suggestion chip "Рекомендуется Java <N>" with a 1-click install button.

### H4: Manual Launcher Update Check & Up-To-Date Visibility
- **Problem:** When running the latest version, the startup update modal does not appear (by design), but users had no explicit visual feedback confirming "Up to date" after manual checks, and manual checking was not exposed in an obvious way.
- **Solution (F4):** Provide an explicit "Проверить обновления" button in `Settings -> Software Updates` and `About` with a visible "Обновлений нет" / "До актуальной версии" status badge.

### H5: Release Vitrine Contract & Gate
- **Status:** Already patched in `master@85dcaa3` via PR #5. `BuildReleaseBody` generates Overview, Changelog, Published Artifacts table, and Verification section; gate verified and `gh release edit v0.6.0` performed.
