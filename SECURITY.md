# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Use the
"Report a vulnerability" button, or create a private advisory:

https://github.com/Aethelis-Projects/Aethelis-Launcher/security/advisories/new

We aim to acknowledge reports within 72 hours and ship a fix in the next patch
release. Please include the affected version, reproduction steps, and a severity
estimate.

Note: for this policy to be fully effective, enable **Private vulnerability
reporting** in repository Settings > Security > Secret scanning and
vulnerability alerts (one-time toggle).
